# 金陵未眠：1937 · Jinling Never Sleeps: 1937

历史剧情互动游戏。1937年11月至1938年的南京，玩家扮演修车铺学徒林怀安，在战争中保护家人、救助他人、记录姓名，并在抉择中走向自己的命运。

## 在线游玩
https://tanghaitian04-debug.github.io/jinling-1937/

手机、平板（含折叠屏展开尺寸）、电脑均可直接游玩，进度保存在本机浏览器。

## 内容
- 序章 + 12 章 + 终章，644 个剧情节点，双路线（提前参军 / 平民救助），参军方向四选
- 24 种结局（结局解析器按优先级确定性判定，含隐藏结局 E24）
- 系统：生命/体力/九维属性、资源、人物关系与下落、背包、姓名记录、隐藏变量
- 互动：对话选择、场景调查、家书拼写、修车、线索核对、证据整理、战地分诊
- 画面：Canvas 程序化绘制的动态场景（秦淮河、城墙、营地、雪夜……），人物走动动画、背景行人与骑行者
- 存档：自动存档 + 3 个手动存档位；章节选择、历史档案（人物/文书/史实卡）、结局图鉴

## 史实与虚构
南京保卫战、1937年12月13日南京沦陷、南京大屠杀、南京安全区等历史背景为真实史实，游戏内以【史实】标注；人物、基层单位与具体情节为艺术虚构，文书标注【虚构文书】，不冒充历史档案。

## 技术
纯静态单页（HTML/CSS/JS，无构建步骤），GitHub Pages 部署；iOS 版为 WKWebView 壳（见 ios-build 分支工作流产物），游戏文件打包在应用内，可离线游玩。
